# 🚀 MeDelivery

**MeDelivery** é um aplicativo de delivery **Open Source** criado com **React Native**.  
O objetivo é aprofundar conhecimentos em mobile e se destacar no mercado, principalmente para empresas da área.

---

## 📦 Entidades

### 👤 User
- name  
- email  
- hashed_password  
- is_deliverer  
- location  

Subtipos:
- Client  
- Deliverer  
  - pix_key  

### 📦 Product
- name  
- amount  
- description  
- url_image  
- location  

### 📍 Location
- latitude  
- longitude  

---

## ✨ Features
- Pagamento via **Pix** (apenas)  
- Perfil cliente e entregador  
- Notificação Push (**FCM**)  
- Código de verificação para cada entrega  
- Pagamento do motorista (retirando uma taxa)  
- Histórico de entregas
